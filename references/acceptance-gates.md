# Acceptance Gates

## Gate 0：输入可用

- 原图已经获得用户批准。
- 原图路径、资产编号、当前版本与输出目录明确。
- 身份、服装、版式、时代特征和背景合同已经锁定。

任一项不满足，停止生成。

## Gate 1：三路并行证据

- 综合色块、线稿、白膜在同一并发批次启动。
- 记录三个任务的启动信息与结果路径。
- 最终合图只能在三个结果都返回以后启动。

若因工具限制无法真正并发，应在执行前向用户说明，不得把串行执行写成并行。

## Gate 2A：综合色块图

通过条件：

- 人物、服装、姿态和版式与原图一致。
- 皮肤、头发、服装等语义颜色没有串区。
- 大明暗关系清楚，细碎纹理已被压缩。
- 色块足够大且连贯，没有马赛克化。
- 背景是单一纯色。

失败示例：纯语义分割导致脸部没有体积；海报化过度导致五官和衣服结构丢失；色块碎成噪点。

## Gate 2B：结构线稿图

通过条件：

- 五官位置、头肩方向、姿态、比例和服装边界准确。
- 线条干净，有主次，无重复鬼线。
- 没有填色、阴影或漫画化改脸。
- 背景纯白。

## Gate 2C：3D白膜图

通过条件：

- 人脸、身体、衣物厚度和褶皱体积可信。
- 比例、姿态、镜头、裁切和版式不变。
- 材质统一为哑光白或浅灰，没有彩色污染。
- 背景为均匀中性灰，人物边界可辨。

## Gate 3：合图准入

三路均为 PASS 才能合图。任一路失败：

1. 只重做失败的那一路。
2. 每一路默认最多重试一次。
3. 第二次仍失败，停止并向用户报告，不用旧失败图凑齐。

## Gate 4：最终候选验收

把原图与候选图并排比较，逐项判断：

### 必须保持

- 同一个人，年龄和五官比例没有漂移。
- 自然不对称、发型、服装、姿态、镜头和版式没有被重设计。
- 真人质感与时代信息保持。

### 必须改善

- 背景更均匀。
- 轮廓更稳定，无黏连和破碎边缘。
- 皮肤、头发、衣物纹理更连贯，随机噪点更少。
- 光色关系更统一，没有脏块和错误小高光。

### 必须避免

- 塑料磨皮、蜡像脸、3D假人感。
- 线稿残留、色块描边、白膜材质污染。
- 过度锐化、过度降噪、布料被抹平。
- 纯色背景仍出现渐变、暗角、光斑或色带。

若“变干净”的收益小于身份或真实感损失，结论为 FAIL，继续保留原图。

## Gate 5：状态与保存

- 三张引导图标记为 `GUIDE`，不能当正式角色资产。
- 最终合图初始标记为 `CANDIDATE` 或 `TESTED`。
- 只有用户明确批准，才可登记为新的 `CURRENT` 版本。
- 不覆盖旧文件；使用递增版本号保存。

建议记录：
