# Prompt Contracts

这些合同用于约束各路职责。将尖括号内容替换成当前资产信息，不要把项目专有剧情写进通用提示词。

## 共同前缀

```text
参考原角色资产：<SOURCE_IMAGE>。
严格保持同一人物身份、年龄、五官比例、自然面部不对称、发型、服装款式、姿态、镜头、裁切、画面版式与时代信息。
不得新增人物、饰品、文字或场景元素。
```

## 综合色块图

```text
基于原角色资产生成综合色块引导图，用于控制最终真人角色图的固有色与大明暗关系。

把皮肤、头发、每件服装、鞋和背景保留为可辨认的语义区域；每个重要材质概括为少量亮部、中间调、暗部大色块。整体控制在少量、连贯、可读的颜色与明度家族中。保留原图真实肤色、发色、服装色和既有光向，但去掉毛孔、细碎发丝、布料纹理、噪点、反复小高光、渐变脏斑和随机颗粒。

色块边界必须服从原人物的真实体积与服装结构，不改变脸型、五官、发型、姿态或服装剪裁。不要线稿，不要描边，不要卡通渲染，不要重新设计角色。

背景为单一纯色 <SOLID_BACKGROUND>，完全均匀，无渐变、暗角、光斑、雾纹和色块。
```

推荐控制尺度：皮肤约3至4档，头发约2至3档，每种主要衣料约2至3档；背景1档。数量是视觉目标，不为凑数拆出碎块。

## 结构线稿图

```text
基于原角色资产生成干净的结构线稿引导图，用于控制最终真人角色图的轮廓与必要细节。

准确保留五官位置、脸部外轮廓、耳朵、发际线、主要发束走向、肩颈关系、肢体比例、手脚、服装领口、门襟、口袋、接缝和鞋型。线条连续、克制、有主次；重要结构清楚，微小皮肤纹理和随机布纹省略。

只允许中性灰黑线条和纯白背景。不填色，不铺明暗，不交叉排线，不做漫画夸张，不改变人物身份、表情、姿态、裁切或版式。
```

## 3D白膜图

```text
基于原角色资产生成3D白膜体积引导图，用于控制最终真人角色图的空间形状、衣物厚度和褶皱体积。

人物与服装统一为哑光白色或浅灰黏土材质。严格保持原人物头身比例、脸部体块、自然面部不对称、发型体积、姿态、镜头、裁切、版式和服装结构。光照只用于清楚说明体积，柔和、均匀、无戏剧化重塑。

不要肤色，不要服装固有色，不要毛孔，不要布纹，不要卡通比例，不要雕塑美化，不要新增结构。背景为单一纯中性灰，无渐变、暗角、光斑、雾纹和色块。
```

## 最终合图

```text
以原角色资产为最高权威，生成同一人物、同一服装、同一姿态、同一镜头和同一版式的干净真人角色资产。

参考职责必须严格分离：
1. 原图只且必须决定人物身份、年龄、五官比例、自然面部不对称、发型、服装、姿态、构图、时代信息和真人摄影质感。
2. 综合色块图只提供固有色和大明暗关系，不继承其海报化色块边缘。
3. 结构线稿图只提供轮廓、五官位置、衣缝和必要边缘，不在成片中留下绘画线条。
4. 3D白膜图只提供体积、厚度、褶皱和空间转折，不继承白色材质或3D塑料感。

消除原图中的随机噪点、背景斑块、不一致的皮肤纹理、破碎布纹、错误小高光和AI黏连，但保留真人应有的轻微毛孔、细发、衣料质感和自然不对称。不要磨皮成塑料，不要变成3D角色，不要美化成另一个人。

背景为单一纯色 <SOLID_BACKGROUND>，完全均匀，无渐变、暗角、光池、雾纹和随机色块。若为全身图，只保留脚下极轻的接触阴影。
```

## 冲突处理

当四份参考不一致时：

1. 身份、服装、姿态、版式冲突：原图优先。
2. 颜色冲突：原图固有色优先，综合色块图只帮助归并大关系。
3. 轮廓冲突：先看原图，再用线稿解释，不得用线稿重画一个人。
4. 体积冲突：先看原图，再用白膜消除含混，不得用白膜重塑审美。
