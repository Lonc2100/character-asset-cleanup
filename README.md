## 原有详细说明

# 角色资产三路并行洗图

这是一个本地个人 Skill，用于把已经批准的人物角色图通过综合色块、结构线稿、3D白膜三路并行生成，再进行一次受约束的最终合图。

它的目标是减少背景斑块、纹理噪点、边缘破碎和材质不一致，同时避免把真人洗成塑料人或另一个人。

## 你可以直接这样说

- `用 $character-asset-cleanup 洗一下这张角色图，三路并行后再合图。`
- `把这个人物资产生成综合色块、线稿和白膜，再重组一张干净候选图。`
- `这张人物图背景和衣服有脏块，按角色资产洗图流程处理。`

## 不做什么

- 不替代角色原始设定与人物验收。
- 不处理普通抠图、单纯换背景或一键磨皮。
- 不生成剧情关键帧、分镜或视频。
- 不在用户确认前覆盖当前正式角色资产。
- 不承诺任何模型都能严格执行控制权重；工具不支持显式控制时，只能通过参考职责和门禁约束。

## 默认流程

1. 锁定已批准原图和不变项。
2. 同时生成综合色块、结构线稿、3D白膜。
3. 分别验收三张引导图，失败路只重试一次。
4. 三路全部通过后生成最终候选图。
5. 对比原图检查干净度收益和身份漂移成本。
6. 用户批准后才登记为新的当前版本。

## 方法依据

- [ControlNet](https://github.com/lllyasviel/ControlNet)：用边缘、分割、深度、法线等条件约束结构。
- [Diffusers ControlNet](https://huggingface.co/docs/diffusers/using-diffusers/controlnet)：多个控制条件可以组合，并分别调节影响强度。
- [IP-Adapter](https://github.com/tencent-ailab/IP-Adapter)：图像提示可与结构控制组合，用来补充人物身份与视觉参考。

本 Skill 并不复制这些工具的实现，也不假定当前生图工具具备 ControlNet 权重接口；它只吸收“参考职责分离、多条件合流、逐路验收”的机制。

## Troubleshooting

- **三路没有并行**：先检查当前工具是否允许并发；不允许时必须如实报告，不能把串行称为并行。
- **人物变了**：降低引导图的身份权威，重新强调原图是身份、服装和构图的唯一最高权威。
- **最终图像插画或3D**：强调线稿、色块和白膜仅提供结构信息，最终材质必须回到原图真人摄影质感。
- **背景仍有色块**：单独重做最终候选，使用纯色背景硬门禁，不必重做已经合格的三张引导图。
- **只是更平滑，没有更真实**：判定失败，保留原图，不把“磨皮”当作“洗干净”。
